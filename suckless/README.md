# My suckless setup

My customized dwm, st, and dmenu builds live directly in this repository.
They are regular folders, with no Git submodules or separate upstream remotes.

- [dwm](dwm/): window manager, configuration, and [status bar scripts](dwm/scripts/).
- [st](st/): terminal and configuration.
- [dmenu](dmenu/): application launcher and configuration.

Clone this repository to get all three builds:

```sh
git clone https://github.com/MehediXT/Mydotfiles.git
cd Mydotfiles/suckless
```

Each build's README contains its build instructions. The source builds are
based on suckless software and BreadOnPenguins' patched builds; the original
copyright notices and licenses are preserved in each folder's `LICENSE`.
