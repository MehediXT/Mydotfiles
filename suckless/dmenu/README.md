## dmenu - Mehedi's personal build

This customized build is maintained in [Mydotfiles](../../README.md).
It is based on BreadOnPenguins' patched dmenu build; see [LICENSE](LICENSE)
for the original copyright notices.

dmenu 5.4 with center 20250407 + xresources 4.9 patches, to be used with ```~/.Xresources``` or a program that sets colorscheme (such as [pywal](https://github.com/dylanaraps/pywal) or [pywal16](https://github.com/eylles/pywal16)). nothing special.

For dmenu scripting walkthroughs and ideas, here are BreadOnPenguins' videos:
- [you're not using dmenu at full power, yet...](https://youtu.be/4JWeU78A95c)
- [clipboard history via a shell script and dmenu](https://youtu.be/6NeEJVghF_k)
- [Bash scripting into dmenu to improve workflow and solve problems](https://youtu.be/h_E3ddNQ1xw)

to install:
```
git clone https://github.com/MehediXT/Mydotfiles.git
cd Mydotfiles/suckless/dmenu
sudo make install
```
